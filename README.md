## アクスタ枠けし（`akusta/`）
写真に写ったアクリルスタンドの透明な枠（アクリル板のフチの線）だけを検出して消すウェブアプリ。
GitHub Pages では `…/akusta/` で開けます。画像はブラウザ内（OpenCV.js）だけで処理され、サーバーには送信されません。

1. アクスタ全体（枠ごと）をドラッグで囲む
2. 「枠を検出」：GrabCut でキャラ部分を保護し、キャラから一定距離にある細い線＝アクリルの縁を自動検出
3. 検出漏れは＋ブラシ、消しすぎは消しゴムで調整（台座なども塗れば消せます）
4. 「枠を消す」：周囲の背景からインペイントで埋めて保存
